# Domain Docs

SlopStop uses a single domain context across its workspaces.

## Before Exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that affect the area being changed.
- Read the standing decisions under `.rpiv/decisions/` before changing a shared boundary or trusted quality gate.
- If one of these files does not exist, continue without inventing a replacement upfront.

## Vocabulary

Use terms exactly as defined in `CONTEXT.md` in issue titles, designs, tests, schemas, and code. If a required concept is absent, either reconsider the new term or record the gap for domain modeling.

## Decision Conflicts

Surface conflicts with an existing ADR or standing decision explicitly. Never override a recorded decision silently; reopen it through a new decision ticket when necessary.
