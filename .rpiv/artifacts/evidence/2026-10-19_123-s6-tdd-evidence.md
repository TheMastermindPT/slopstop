## Method

- Every log is in `2026-10-19_123-s6-tdd/`, written by `tdd-run.sh`: the header holds the parent commit, the working-tree digest, the command and the start time; the footer holds the exit code.
- Digest: sha256 (first 16 hex) of `git diff --binary HEAD` plus one `path hash-object` line per untracked file, both **excluding `.rpiv`**, so the evidence logs never move it. `e3b0c44298fc1c14` is the clean tree.
- Bindings: `bind.py` backs the source up, replaces one exact snippet, runs the named test through `tdd-run.sh`, restores by copy, and appends a line proving the restored blob and the digest equal the ones before.
- Unit runs: `pnpm exec vitest run --project desktop-main <files> [-t <name>]` from the worktree root; B7's register row: `--project harness apps/harness/scripts/check-effect-diagnostics.test.mjs`.
