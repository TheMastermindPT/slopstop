## Method

- Every log is in `2026-10-19_123-s7-tdd/`, written by `tdd-run.sh`. The header holds the parent commit, the **tree** and the working-tree digest, the command and the start time; the footer holds the exit code.
- Tree: `git write-tree` of a temporary index holding the working tree, **excluding `.rpiv/artifacts/evidence`**; so a tree in a log equals the commit tree when that state is committed (`9da01af` → `09fdfb18`, `f3d2c8f` → `94190546`). Digest: the s6 formula (sha256 of `git diff --binary HEAD` plus untracked files, excluding `.rpiv`).
- Bindings: `bind.py` (one file) or `bind2.py` (several) backs the source up, replaces one exact snippet (`bindings/<name>.old` → `.new`), runs the named rows through `tdd-run.sh`, restores by copy, and appends a line proving the restored file's sha256 and the tree equal the ones before.
- Unit runs: `pnpm exec vitest run --project desktop-main <s7-files.txt> [-t <name>]` from the worktree root; B8's register row: `--project harness apps/harness/scripts/check-effect-diagnostics.test.mjs`.
