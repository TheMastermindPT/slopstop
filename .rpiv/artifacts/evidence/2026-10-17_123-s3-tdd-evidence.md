## Opening measurement

### Tool

`close-measurement.test.ts`, run alone through its own Vitest config from `apps/harness`. One root per shape is migrated once, before any timed window. Each sample opens a fresh authority over that root (`ensureCurrent({ createIfMissing: false })`), sets up its shape, and only `stop()` is timed, with a 15 s bound. Percentiles are nearest-rank.

- **M-idle:** no work in flight.
- **M-drain:** one admitted write transaction runs three statements on a scratch table, then commits and closes. `stop()` is called after the first of them settles. A drain proof fails the sample if `stop()` settles before that transaction is closed.
- **Tool choice (not a contract change):** the scratch table is a `TEMP` table, created inside that transaction just before its three statements. The application schema verifier refuses any extra table in the main schema (`database-schema-verifier.ts:493`, "Database contains an unexpected table set."), so a permanent scratch table would break `ensureCurrent` on the next fresh authority.
