# Standing Decisions

The decision files in this directory were copied byte-for-byte from the `rpiv-claude` repository on 2026-08-14 and explicitly adopted for SlopStop.

- `degrade-distinguishes-broken.md` protects every trusted gate and recovery path from reporting failure as clean state.
- `shared-vocab-union.md` protects protocol, status, capability, and file-vocabulary extraction from silently narrowing accepted values.

Their original `source` paths remain provenance references to the originating repository and may not resolve inside SlopStop.
